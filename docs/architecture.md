# Viora System Architecture

> **App Tagline:** *“Go live. Find your people.”*

Viora is a high-performance live-streaming mobile application designed with enterprise-grade modularity, high availability, zero-trust security rules, and real-time interactive telemetry.

## 2. Core Pillars

### Live Streaming (Agora RTC Engine)
- Agora handles all video capture, encoding, transmission, adaptive bitrate scaling, and low-latency audio/video delivery.
- Secure token authentication via short-lived tokens generated by Supabase Edge Functions.

### Data & State Management (Supabase + MVVM)
- **Supabase PostgreSQL:** Stores user profiles, follow graphs, live rooms, gift transactions, and moderation audit logs.
- **Row Level Security (RLS):** Strict zero-trust database policies. Balances and gifts can never be updated directly by client queries; all financial mutations flow through atomic server-side functions.
- **Supabase Realtime:** Broadcasts chat messages, viewer counters, floating reaction hearts, and celebratory gift banners with minimal latency.

### Financial Ledger & Creator Economy
- **Virtual Gifts:** Rose (1 coin), Coffee (5 coins), Sparkle Heart (10 coins), Fire Energy (25 coins), Diamond Ring (50 coins), Sports Car (200 coins), Galactic Rocket (500 coins), Viora Crown (1000 coins).
- **Revenue Split:** 70% of gift coin value is credited as Diamonds to the broadcaster (100 diamonds = $1.00 USD).
- **Idempotency Protection:** Double charges are rejected using unique idempotency keys on every transaction.

### Safety & Trust Center
- Automated rate limiting on chat.
- Live room moderation tools: Pin comment, delete message, mute user, kick viewer.
- Admin dashboard review queue with instant stream termination and user ban enforcement.
